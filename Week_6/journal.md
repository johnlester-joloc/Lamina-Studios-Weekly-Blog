# Day 1
I spent the weekends researching about Apache and I finally found the issue with the configuration. I proceeded with the activity, performed a basic SQL Injection from the Kali machine, and then updated the old DVWA code for software hardening, and then tried the same SQL Injection trick which this time no longer worked thanks to the hardening. I finally finished Weekly Task 8. This was proof that software setup can be just as hard as programming.
